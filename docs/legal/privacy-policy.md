# Политика обработки персональных данных

> **Черновик.** Документ — заготовка, а не юридическая консультация. Поля `[ЗАПОЛНИТЬ]` и номера законов нужно проверить с юристом до публикации.

Редакция от `[ЗАПОЛНИТЬ: дата]`.

## 1. Кто обрабатывает данные

Оператор персональных данных — `[ЗАПОЛНИТЬ: ФИО / наименование, ИНН, ОГРН, адрес]` (далее — «Оператор»), владелец платформы «Кибердвор» по адресу `[ЗАПОЛНИТЬ: домен]`.

Оператор направил уведомление об обработке персональных данных в Роскомнадзор: `[ЗАПОЛНИТЬ: дата, регистрационный номер]`.

## 2. Какие данные мы получаем

| Данные                                           | Откуда                            | Зачем                                               |
| ------------------------------------------------ | --------------------------------- | --------------------------------------------------- |
| Идентификатор и логин Яндекс ID                  | Яндекс ID при входе               | вход на платформу, «один человек — один аккаунт»    |
| Email                                            | Яндекс ID                         | служебные уведомления                               |
| Дата рождения                                    | Яндекс ID или вводит пользователь | проверка возрастных ограничений игр (436-ФЗ)        |
| SteamID, ник и аватар Steam                      | Steam при привязке                | участие в турнирах, проверка составов в матчах      |
| Ранг в игре, часы в игре                         | OpenDota, FACEIT, Steam Web API   | анкета игрока, стартовый рейтинг                    |
| Анкета: роли, время игры, языки, ссылки на клипы | вводит пользователь               | подбор игроков в драфте                             |
| Результаты матчей, рейтинг, репутация            | платформа                         | работа турниров                                     |
| Сетевой адрес ПК-хоста матча CS2                 | десктоп-клиент                    | проверка доступности сервера, только на время матча |
| ID чата Telegram                                 | пользователь сам привязывает бота | уведомления о матчах                                |

Мы не запрашиваем у Яндекс ID других данных и не получаем пароли.

## 3. Что видно другим

Публично отображаются только ник, аватар, рейтинг, анкета и репутация. Логин, email и дата рождения не публикуются и не передаются другим пользователям.

## 4. Где и сколько хранятся данные

Базы данных с персональными данными граждан РФ находятся на серверах в Российской Федерации (`[ЗАПОЛНИТЬ: провайдер — Yandex Cloud / Selectel]`).

Данные хранятся, пока действует аккаунт, и удаляются в течение `[ЗАПОЛНИТЬ: срок]` после его удаления, если закон не требует хранить их дольше.

## 5. Передача третьим лицам

Мы не продаём и не передаём персональные данные третьим лицам, кроме случаев, предусмотренных законом. Для работы платформы используются Яндекс ID, Steam, OpenDota, FACEIT и Telegram. Им передаётся только то, что необходимо для конкретного запроса (например, SteamID для получения ранга).

## 6. Права пользователя

Пользователь может запросить сведения об обработке своих данных, их уточнение или удаление, а также отозвать согласие на обработку, написав на `[ЗАПОЛНИТЬ: email]`. Отзыв согласия означает удаление аккаунта: без данных участвовать в турнирах нельзя.

## 7. Защита данных

Доступ к данным имеют только `[ЗАПОЛНИТЬ: роли]`. Соединение защищено HTTPS. Персональные данные не пишутся в журналы сервера.

## 8. Изменения политики

Новая редакция публикуется на этой странице. О существенных изменениях пользователи узнают при входе.
